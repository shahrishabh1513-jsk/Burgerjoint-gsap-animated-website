# 🌟 Project Overview

**BurgerJoint** is a modern animated burger brand landing page built using **HTML5, CSS3, JavaScript, GSAP, ScrollTrigger, and Locomotive Scroll**.

The website focuses on delivering an immersive and engaging user experience through advanced animations, smooth scrolling effects, and modern storytelling design.

### 🎯 Project Goals

- Create a visually engaging burger brand website
- Implement advanced GSAP animations
- Explore smooth scrolling interactions
- Build a responsive and modern UI
- Practice animation-driven web storytelling
